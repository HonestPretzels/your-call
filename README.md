# your-call

A Claude Code plugin for staying in the loop when an agent writes your code, without approving every diff.

Instead of reviewing each edit as it happens, you shape the plan and interfaces with the agent up front. While it works, the agent stops to ask you about decisions that are expensive to change or that it shouldn't make alone, and logs every other judgment call. When the branch is ready, it builds a review page: what changed, where, every decision with its reasoning, and how the behaviour was checked. You and your reviewers mark each decision, and the agent works through the ones you want changed.

Work in progress.
